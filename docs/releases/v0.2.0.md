# Release v0.2.0

Release date: 2026-04-26

## Summary

`v0.2.0` is the first public beta release of `acmed-plugin-sdk` for ACMED gen2
remote issuer integrations.

## Highlights

- Added canonical plugin contract models (`IssueRequest`, `IssueResult`,
  `Capabilities`, `HealthStatus`).
- Added typed HTTP client and FastAPI server scaffolding for remote plugins.
- Added bearer token support for current+next token rollout.
- Added API contract reference at `docs/plugin-api-contract.md`.
- Hardened CI/release workflows with SHA-pinned core actions.
- Release workflow now waits for `CI` via
  `rohzb/ci-actions/wait-for-workflows`.

## Compatibility Notes

- Package/API version remains `0.2.0` and follows pre-1.0 semver policy.
- No breaking contract change is introduced relative to the current v1 SDK API
  contract.
